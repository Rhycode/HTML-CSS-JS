# Salil Chowdhury - Premium Portfolio Website

A stunning, premium portfolio website with beautiful animations, modern design, and luxurious aesthetics.

## ✨ Features

- **Premium Design**: Sophisticated dark theme with gradient overlays and glass morphism effects
- **Smooth Animations**: CSS and JavaScript animations for an engaging user experience
- **Responsive Layout**: Perfectly optimized for all devices (desktop, tablet, mobile)
- **Interactive Elements**: Hover effects, floating shapes, and dynamic content
- **Modern Technologies**: Built with HTML5, CSS3, and vanilla JavaScript
- **Performance Optimized**: Debounced scroll events and smooth animations

## 🎨 Design Highlights

- **Color Scheme**: Dark theme with purple-pink gradients and accent colors
- **Typography**: Playfair Display for headings, Inter for body text
- **Effects**: Glass morphism, backdrop blur, gradient overlays
- **Animations**: Floating shapes, scroll-triggered animations, typing effects
- **Custom Cursor**: Interactive cursor that responds to hover states

## 📱 Sections

1. **Hero Section**: Eye-catching introduction with animated text and floating elements
2. **About Section**: Professional overview with animated statistics
3. **Services Section**: Interactive service cards with hover effects
4. **Portfolio Section**: Project showcase with overlay effects
5. **Contact Section**: Beautiful contact form with glass morphism design

## 🚀 Getting Started

1. **Open the website**: Simply open `index.html` in your web browser
2. **Local Server** (recommended): Use a local server for best experience:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Using PHP
   php -S localhost:8000
   ```
3. **Navigate to**: `http://localhost:8000`

## 🛠️ Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #ec4899;
    --accent-color: #f59e0b;
    /* ... other colors */
}
```

### Content
- Update text content in `index.html`
- Replace placeholder images with actual photos
- Modify contact information
- Add real portfolio projects

### Animations
- Adjust animation timing in CSS
- Modify JavaScript interactions in `script.js`
- Add new scroll-triggered animations
